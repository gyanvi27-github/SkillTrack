# SkillTrack Burnout LSTM — PHP Backend
## Setup & Deployment Guide

---

## Architecture

```
CSV Data
   │
   ▼
burnout_backend.php          ← ALL data logic lives here
   ├── Import CSV → MySQL
   ├── Feature Engineering (rolling avg, slope, flags)
   ├── MinMax Scaling → stored in scaler_params table
   ├── Build 7-day sequences
   └── proc_open() → predict.py ← LSTM forward pass only
                         │
                         └── burnout_lstm_model.keras
                                (trained once by original .py)
   │
   ▼
MySQL (4 tables) + burnout_predictions.json + burnout_report.csv
   │
   ▼
Frontend HTML/JS dashboard (burnout_backend.php?action=predictions)
```

---

## Files

| File | Purpose |
|------|---------|
| `burnout_backend.php` | Main PHP backend — data pipeline + HTTP API |
| `predict.py` | Python microservice — LSTM inference only |
| `schema.sql` | MySQL table definitions |
| `burnout_lstm_model.keras` | **Generated by training** (see Step 1) |

## Step-by-Step Setup

### 1. Train the model ONCE (Python — run locally or on server)
```bash
pip install tensorflow scikit-learn pandas numpy joblib
python3 burnout_lstm_backend.py     # original Python file
```
This produces `burnout_lstm_model.keras` — upload this to your server.

### 2. Create MySQL database
```bash
mysql -u root -p < schema.sql
```
Or paste `schema.sql` into phpMyAdmin on Hostinger.

### 3. Configure DB credentials
Edit the top of `burnout_backend.php`:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'skilltrack_db');
define('DB_USER', 'your_db_user');
define('DB_PASS', 'your_db_password');
```

### 4. Run the full pipeline (CLI)
```bash
# Full pipeline: import → engineer → predict → report
php burnout_backend.php --action=all --csv=student_mood_checkins.csv

# Or step by step:
php burnout_backend.php --action=import   --csv=student_mood_checkins.csv
php burnout_backend.php --action=engineer
php burnout_backend.php --action=predict
php burnout_backend.php --action=report
```

### 5. HTTP API (for frontend JS)
Your frontend can call:

| URL | Returns |
|-----|---------|
| `burnout_backend.php?action=predictions` | Full JSON for all students |
| `burnout_backend.php?action=student&id=5` | Single student + history |
| `burnout_backend.php?action=summary` | Risk level summary counts |

## Hostinger / LiteSpeed Deployment

1. Upload all files to `public_html/skilltrack/`
2. Ensure Python 3 is available (`python3 --path` in SSH terminal)
3. Set PHP `exec()` / `proc_open()` enabled (usually on by default)
4. Set file permissions:
   ```
   chmod 644 burnout_backend.php predict.py
   chmod 666 burnout_predictions.json burnout_report.csv
   ```
5. Create MySQL DB via Hostinger hPanel → Databases
6. Run the pipeline via SSH:
   ```bash
   cd ~/public_html/skilltrack
   php burnout_backend.php --action=all --csv=student_mood_checkins.csv
   ```

---

## Notes

- **Model retraining**: Only needed when you have new data. Re-run the original
  `burnout_lstm_backend.py` and re-upload `burnout_lstm_model.keras`.
- **Live predictions**: Call `burnout_backend.php --action=predict` as a cron job
  nightly to refresh scores without retraining.
- **Scaler**: Stored in MySQL (`scaler_params` table) — no `.pkl` file needed at runtime.
